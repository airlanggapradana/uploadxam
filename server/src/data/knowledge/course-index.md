# Course Index

## Purpose

Dokumen ini merupakan indeks utama seluruh mata kuliah yang tersedia pada Knowledge Base Kurikulum Universitas Muhammadiyah Surakarta (UMS).

Dokumen ini tidak berisi deskripsi lengkap setiap mata kuliah. Seluruh informasi detail disimpan pada dokumen individual di dalam folder `courses/`.

Course Index digunakan untuk:

- menemukan mata kuliah berdasarkan nama
- menemukan mata kuliah berdasarkan kode
- menemukan mata kuliah berdasarkan semester
- menemukan mata kuliah berdasarkan program studi
- menemukan mata kuliah berdasarkan kategori
- melakukan normalisasi hasil retrieval

---

# Index Structure

Setiap mata kuliah memiliki atribut berikut.

- Course ID
- Course Code
- Course Name
- Study Program
- Semester
- Credits (SKS)
- Category
- Concentration (jika ada)
- Document Reference
