# Program Overview

Program Studi Ilmu Komunikasi Universitas Muhammadiyah Surakarta membekali mahasiswa dengan pengetahuan, keterampilan, dan sikap profesional di bidang komunikasi melalui pendekatan teoritis maupun praktis.

Kurikulum dirancang untuk mengembangkan kemampuan mahasiswa dalam memahami proses komunikasi, media, hubungan masyarakat, komunikasi pemasaran, komunikasi digital, produksi media, penelitian komunikasi, serta bidang komunikasi lainnya sesuai dengan kurikulum yang berlaku.

---

# Learning Focus

Program Studi Ilmu Komunikasi memiliki fokus pembelajaran pada:

- Teori Komunikasi
- Komunikasi Massa
- Public Relations
- Jurnalistik
- Penyiaran
- Komunikasi Digital
- Komunikasi Pemasaran
- Produksi Media
- Penelitian Komunikasi
- Etika Komunikasi
