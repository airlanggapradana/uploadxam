# Purpose

Dokumen ini berisi seluruh mata kuliah pilihan pada Program Studi Ilmu Komunikasi Universitas Muhammadiyah Surakarta.

Informasi pada dokumen ini digunakan sebagai referensi ketika pengguna menanyakan:

- daftar mata kuliah pilihan
- semester pengambilan mata kuliah pilihan
- jumlah SKS mata kuliah pilihan
- kode mata kuliah pilihan

Seluruh informasi mengacu pada kurikulum resmi.
