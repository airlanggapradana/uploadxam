# Overview

Konsentrasi Rekayasa Perangkat Lunak (RPL) berfokus pada proses analisis, perancangan, pengembangan, pengujian, hingga pemeliharaan perangkat lunak.

Mahasiswa mempelajari bagaimana membangun sistem perangkat lunak yang berkualitas, scalable, mudah dipelihara, serta sesuai dengan kebutuhan pengguna dan industri.
