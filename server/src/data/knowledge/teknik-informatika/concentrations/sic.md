# Overview

Konsentrasi Sistem Interaktif Cerdas (SIC) berfokus pada pengembangan sistem berbasis Artificial Intelligence untuk menghasilkan solusi yang mampu belajar, mengenali pola, memahami data, dan membantu pengambilan keputusan.
