# Program Overview

Program Studi Kecerdasan Buatan Universitas Muhammadiyah Surakarta mempersiapkan mahasiswa untuk mengembangkan solusi berbasis Artificial Intelligence melalui penguasaan teori, algoritma, analisis data, serta pengembangan sistem cerdas.

Kurikulum dirancang untuk membangun kompetensi mahasiswa mulai dari dasar komputasi, matematika, pemrograman, data science, machine learning, computer vision, natural language processing, hingga implementasi teknologi kecerdasan buatan pada berbagai bidang aplikasi.

---

- Artificial Intelligence

- Deep Learning

- Data Science
- Intelligent Systems
- Robotics
