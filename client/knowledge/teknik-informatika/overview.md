# Program Overview

Program Studi Teknik Informatika Universitas Muhammadiyah Surakarta berfokus pada pengembangan kompetensi di bidang rekayasa perangkat lunak, sistem jaringan, kecerdasan buatan, data science, serta teknologi komputasi modern.

Mahasiswa memperoleh landasan teori dan praktik melalui mata kuliah dasar komputasi, pengembangan perangkat lunak, jaringan komputer, kecerdasan buatan, serta mata kuliah peminatan pada semester lanjutan.

---

# Learning Focus

Program studi ini memiliki fokus pembelajaran pada:

- Software Engineering
- Artificial Intelligence
- Data Science
- Computer Network
- Cloud Computing
- Internet of Things
- Web Development
- Mobile Development
- Computer Vision
- Machine Learning
