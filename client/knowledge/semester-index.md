# Semester Index

## Purpose

Dokumen ini merupakan indeks seluruh semester yang tersedia pada Knowledge Base Kurikulum Universitas Muhammadiyah Surakarta (UMS).

Semester Index berfungsi sebagai entry point ketika pengguna mencari informasi berdasarkan semester.

Dokumen ini **tidak menyimpan daftar lengkap mata kuliah**. Informasi detail tersedia pada dokumen semester masing-masing.

# Retrieval Strategy

Apabila query mengandung:

- semester
- sem
- angka semester (1-8)

maka lakukan langkah berikut:

1. Identifikasi nomor semester.
2. Identifikasi program studi (jika disebutkan).
3. Gunakan dokumen semester yang sesuai.
4. Jika program studi tidak disebutkan, minta klarifikasi kepada pengguna.

## Query

Semester akhir

Response

Semester akhir pada seluruh program studi adalah Semester 8.

Silakan tentukan program studi apabila Anda ingin melihat daftar mata kuliahnya.
