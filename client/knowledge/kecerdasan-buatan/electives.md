# Purpose

Dokumen ini berisi seluruh mata kuliah pilihan pada Program Studi Kecerdasan Buatan Universitas Muhammadiyah Surakarta.

Dokumen digunakan sebagai referensi ketika pengguna mencari informasi mengenai:

- daftar mata kuliah pilihan
